# All KPI's backend (optional module)

Read-only endpoints under `/api/all-kpis/` for the optional All KPI's page. No models, migrations, settings or
`INSTALLED_APPS` entry: the app is reached only through one line in `config/urls.py`.

The full documentation (calculations, endpoints, pending items and the removal procedure) is in
`frontend/src/features/all-kpis/README.md`.
